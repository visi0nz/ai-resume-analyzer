# AI Resume Analyzer | Emre Civas
AI Resume Analyzer is a web app that extracts text from uploaded resumes, analyzes fit for a job description, and returns structured feedback. 

Key features:<br>
Upload PDF or image resumes (OCR extraction)<br>
AI-driven analysis and JSON-formatted feedback for integration<br>
File storage, versioning, and simple KV persistence<br>

Tech stack:<br>
React + TypeScript<br>
Vite<br>
Custom Puter AI/FS/KV integration<br>
OCR via ai.img2txt<br>
