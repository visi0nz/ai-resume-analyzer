# AI Resume Analyzer | Emre Civas
AI Resume Analyzer is a web app that extracts text from uploaded resumes, analyzes fit for a job description, and returns structured feedback. 

Key features:
Upload PDF or image resumes (OCR extraction)
AI-driven analysis and JSON-formatted feedback for integration
File storage, versioning, and simple KV persistence

Tech stack:
React + TypeScript
Vite
Custom Puter AI/FS/KV integration
OCR via ai.img2txt
